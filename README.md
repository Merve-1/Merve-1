## 💫 About Me

I'm a **Cybersecurity Engineer** with a background in software development and a strong interest in **Application Security, DevSecOps, and Cloud Security**.

My focus is on building secure applications, identifying vulnerabilities, and integrating security into the software development lifecycle.

I have experience with backend development, RESTful APIs, and secure application development, alongside practical exposure to security testing and DevSecOps tools.

I'm particularly interested in:

- 🔐 **Application Security:** Web application security, API security, vulnerability assessment, and secure coding.
- ⚙️ **DevSecOps:** CI/CD security, Docker, GitHub Actions, and automated security testing.
- ☁️ **Cloud Security:** AWS security fundamentals, identity and access management, and cloud infrastructure security.
- 🛡️ **Security Operations:** SIEM, threat detection, log analysis, and incident investigation.
- 🤖 **AI Security:** Exploring security challenges, vulnerabilities, and threats affecting AI systems.

I enjoy combining software engineering and cybersecurity to build applications that are not only functional but also secure.

### 📂 About This GitHub Portfolio

This GitHub profile showcases my journey at the intersection of **Software Engineering, Application Security, and DevSecOps**.

You'll find a collection of software development projects, cybersecurity labs, security experiments, and technical documentation covering secure application development, web and API security, vulnerability assessment, and DevSecOps practices.

It also includes educational repositories, coding exercises, assignments, and learning resources from courses I've taken or taught.
